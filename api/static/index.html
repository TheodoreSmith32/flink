Background Jobs

Job di sini disubmit dari cell SQL ATAU Python (tombol "Submit Job") dan jalan SELAMANYA di background, beda dengan Run biasa yang berhenti begitu hasilnya selesai/preview. Job SQL di-Stop lewat Flink job_client.cancel() yang terjamin berhenti. Job Python di-Stop cuma REQUEST kooperatif lewat stop_event -- kalau kode cell-nya tidak mengecek itu di loop-nya, job akan tetap jalan walau sudah di-Stop. Tapi ini masih proses embedded -- kalau server uvicorn ini mati/di-restart, SEMUA job di bawah ikut mati. Ini BUKAN Flink session cluster beneran (lihat README.md untuk rencana Dinky + Flink cluster ke depannya).
